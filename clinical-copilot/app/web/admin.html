Create user

Provisioning new accounts is done in OpenEMR's admin UI, not in this app. OpenEMR is the source of truth for users, role assignments, and password hashes; the co-pilot validates credentials against OpenEMR's password-grant OAuth and does not maintain a parallel user store. To add a clinician, sign in to OpenEMR's admin panel and use the user-management page there. The co-pilot's role-based view (this page) auto-picks-up the new user once they log in for the first time.

Configuring who is an admin in this app is a separate concern controlled by the ADMIN_USERNAMES env var on the deploy host.
