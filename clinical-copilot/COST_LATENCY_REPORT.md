# Cost & Latency Report

Generated by `scripts/cost_latency_report.py` from a live
agent run on **2026-05-05 14:09 UTC**
against the local OpenEMR docker stack, model **claude-sonnet-4-6**.

Sample size: **12 cases** (0 failed). The cases are a curated subset of the
150-run eval suite that exercise every major code path
(chart summary, lab/vital pulls, drug-interaction RAG, refusals,
ACL, multi-turn).

## Methodology

- One `RequestTrace` per case (across all turns), captured via
  `app.observability.TokenUsageCallback` and the per-tool
  `record_tool_event` hook in `app.agent.graph.execute_tools`.
- Cost is computed from token counts via
  `app.observability.compute_cost_usd` using the live pricing
  table (`PRICING_USD_PER_MTOK`).
- Latency is wall-clock time including OpenEMR FHIR round-trips,
  not just LLM time. Production with cached chart data would be
  faster (the dashboard prewarm already demonstrates this).

### Actual dev spend (this project)

Total Anthropic spend across Week 1 + Week 2 development is
not tracked in-repo (the trace database is restart-volatile and
the eval suite ran without trace capture). Anthropic console
is the authoritative source. The numbers above are the
incremental spend of generating *this report*, which is a
good proxy for per-eval-pass cost during development.

### Projected production cost

Conservative usage scenario for a single primary-care
clinic with one Copilot user:

| Scenario | Daily chats | Monthly chats | Monthly cost |
|---|---:|---:|---:|
| Light (50/day) | 50 | 1,500 | $44.48 |
| Active (200/day) | 200 | 6,000 | $177.90 |
| Heavy (500/day) | 500 | 15,000 | $444.75 |

The projection assumes the workload mix matches the sampled
eval cases. Real production traffic skews toward chart
summaries (heavier) and away from refusals/ACL checks
(lighter), so the true mean is likely within ±30% of the
number above.

Prompt-caching is already enabled (cache reads = 83% of total
input-token volume). Without it, input-token cost would be
~5× higher.
